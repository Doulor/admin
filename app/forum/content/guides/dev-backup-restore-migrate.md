这篇写怎么备份一个环境的数据、怎么把备份恢复到另一台机器或者另一个环境。

1. 控制台的「备份」页面能一键下载一份完整备份：数据库快照、站点文件、图片，还有一份带校验值的清单文件；备份里不含任何密钥，也不含登录会话。
2. 迁移到新环境或者新机器时，先按《发布与部署》（./t920）把目标环境的两套 Docker 栈、宿主 nginx、DNS/TLS 这些前置条件配好，再用这份备份恢复：

```
node scripts/backup-restore.mjs <备份文件路径> --environment <production|preview>
```

把备份恢复进目标环境的数据目录；具体参数以脚本自己的帮助信息为准。
3. 在预发布和正式之间互相迁移数据，同样是先导出一份备份，再到另一个环境恢复——两个环境各自独立的数据卷不会自动同步，这一步必须手动做。
4. 恢复操作会覆盖目标环境现有的全部数据，操作前确认目标环境选对了；需要的话先给目标环境自己也做一份备份，留一个能回退的点。
5. 恢复完成后按《运维：健康检查、日志与常见故障》（./t923）确认服务正常，再通知相关的人这次迁移已经完成。
